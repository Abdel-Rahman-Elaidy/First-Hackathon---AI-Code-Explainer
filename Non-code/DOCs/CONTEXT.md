# AI Code Learning Companion

A web application that helps beginner developers actively understand AI-generated code by reading it, rewriting a removed section, and explaining their reasoning — then receiving AI feedback on both.

## Language

**Learning Loop**:
The full sequence a user moves through for a single piece of code: Understand → Rewrite → Explain → Evaluate → (Hint / Retry) → Success.
_Avoid_: session, exercise, challenge, quiz

**Submitted Code**:
The code the user pastes into the app at the start of the Learning Loop. It may have been written by the user, generated by AI, or a mix.
_Avoid_: original code, user code, input code

**Gap**:
The section removed from the Submitted Code that the user is asked to rewrite. Chosen by the AI for maximum pedagogical value.
_Avoid_: missing section, blank, hole, placeholder

**Code Context**:
The Submitted Code displayed on the Learner page with the Gap replaced by a comment placeholder. Gives the user the surrounding code to understand where and why the Gap belongs.
_Avoid_: code with gap, partial code, redacted code

**Rewrite**:
The user's attempt to reconstruct the Gap. An equivalent solution is accepted — exact reproduction of the original Gap is not required.
_Avoid_: answer, submission, solution

**Explanation**:
The user's written reasoning for why they wrote their Rewrite the way they did and what it does. Evaluated alongside the Rewrite — both must pass for an attempt to succeed.
_Avoid_: reasoning, justification, comment

**Attempt**:
One submission of a Rewrite + Explanation pair for evaluation. Up to 5 attempts are allowed before the Solution is revealed.
_Avoid_: try, submission, guess

**Attempt Counter**:
The running count of failed Attempts in the current Learning Loop. Resets to zero at the start of each new Learning Loop. Does not reset after the Solution is revealed.
_Avoid_: try counter, fail count

**Hint**:
AI-generated guidance given after a failed Attempt. Hints grow progressively more revealing with each Attempt but never contain the Solution until Attempt 5.
_Avoid_: clue, tip, feedback (feedback is broader — see below)

**Feedback**:
The full AI response after evaluation: includes correctness result, what was wrong or right, and (if incorrect) a Hint.
_Avoid_: response, result, evaluation output

**Solution**:
The actual Gap code revealed by the AI after 5 failed Attempts. Revealing the Solution does not end the Learning Loop — the user must complete one final successful Rewrite before the Loop closes.
_Avoid_: answer, correct code, original section

**Big Picture Explanation**:
The AI's high-level description of the Submitted Code: what it does, why it exists, its major components, and overall flow. Shown on the Explainer page.
_Avoid_: overview, summary

**Line-by-Line Explanation**:
The AI's beginner-friendly walkthrough of each meaningful line or block of the Submitted Code. Shown on the Explainer page alongside the Big Picture Explanation.
_Avoid_: detailed explanation, code walkthrough

## Pages

**Home Page**:
The entry point. Contains the code input area and the "Start Explanation" button that triggers the Learning Loop.

**Explainer Page**:
Shows the Submitted Code alongside the Big Picture Explanation and Line-by-Line Explanation. The user proceeds from here to the Learner Page.

**Learner Page**:
The active learning surface. Shows the Code Context, the Rewrite editor, the Explanation input, the Attempt Counter, and the "Check My Answer" button.
