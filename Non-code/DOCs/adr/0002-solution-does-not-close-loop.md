# Solution reveal does not end the Learning Loop

After 5 failed Attempts the AI reveals the Solution, but the Learning Loop does not close. The user must complete one additional successful Rewrite (and Explanation) before the loop is marked complete.

This prevents the Solution from being an escape hatch. A user who reaches Attempt 5 must still demonstrate understanding — they cannot simply read the Solution and move on. The Solution becomes a learning resource, not a skip button. The post-solution Attempt is not subject to the 5-attempt limit; the user keeps trying until they succeed.

## Consequences

The Attempt Counter must distinguish between pre-solution and post-solution attempts. The UI on the Learner page should communicate clearly that the Solution has been revealed and this is the final required Rewrite.
